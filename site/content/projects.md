## 2D Platformer Game

**Status:** In development  
**Tech Stack:** Java, libGDX  
**Visual Assets:** Self-designed characters, backgrounds, and game objects

### Overview

A 2D side-scrolling platformer currently in development, built with
Java and libGDX.

I designed the character sprites, backgrounds, and game objects,
creating the game's visual assets alongside its gameplay systems.
The game features platform navigation, collectible stars, and an
Aquarius-themed stage connected through dialogue sequences.


### Features

- **Character Controls:** Keyboard-based movement and jumping, with crawling animations.
- **Collision Detection:** Horizontal and vertical collision handling for platforms, including landing and ceiling collisions.
- **Character Animation:** Sprite-sheet animations for idle, movement, jumping, and crawling states.
- **Camera System:** A player-following camera constrained to the map boundaries.
- **Collectibles and Scoring:** Collectible stars that increase the player's score.
- **Respawn System:** Returns the player to the starting position after falling off the map.
- **Dialogue and Transitions:** Keyboard-controlled dialogue progression and fade effects between screens.
- **Original Visual Assets:** Self-designed character sprites, backgrounds, and game objects.

### Technical Focus

- Implementing frame-time-based movement, gravity, and jump mechanics.
- Handling horizontal and vertical collisions separately.
- Separating the character's visual size from its collision hitbox.
- Switching character animations based on movement and airborne states.
- Managing game screens and texture resources using libGDX.

### Current Progress

The source code includes core gameplay systems, dialogue sequences,
and an initial Aquarius-themed stage.

The project is still in development, with ongoing gameplay refinement
and additional content planned.
